
# Прцесс разработки

## Команда агентов

Работа над фичами идёт командой агентов по регламенту `docs/agents/TEAM.md`. Его читает
каждый агент перед работой.

- Роли и их файлы: `.claude/agents/` (геймдизайнер-аналитик, архитектор, тест-инженер,
  программист, ревьюер, левел-дизайнер, звуковой дизайнер, ассет-конвейер). Ведущий —
  основная сессия.
- Ассеты и звуки — только по `docs/art/ASSET_POLICY.md`: по умолчанию CC0, максимум CC BY
  с указанием автора. Арт- и аудио-референсы — `docs/art/REFERENCES.md` (стиль выбирает
  владелец), правила звука — `docs/audio/SOUND.md`.
- Артефакты фичи — `docs/work/<ID>-<slug>/` по шаблонам `docs/agents/templates/`.
- Владелец решает в точках H0–H3 (задача, карточка, план с сетевыми и проектными
  изменениями, ручная проверка ощущения). Вопросы владельцу — файлом `decision-NN.md`.
- `DESIGN.md` агенты не правят никогда. Запрет закреплён в `.claude/settings.json`.
- Шаг считается сделанным, только если к нему приложен вывод `tools\run_tests.cmd`.
- Запуск фичи: команда `/feature <ID> <формулировка задачи>`.
