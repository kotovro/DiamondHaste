# Звук в Diamond Heist — правила

Для звукового дизайнера, программиста и левел-дизайнера. Направление (стиль музыки и
звуков) — в `docs/art/REFERENCES.md`, раздел «Звук»; пока владелец его не утвердил,
звуки — временные заглушки из CC0-паков.

## Задачи звука по важности

1. **Обратная связь о состоянии игры.** Игрок слышит то, что важно, даже не глядя:
   алмаз повреждён (и насколько), выносливость кончается, рядом лазер, охрана близко,
   чекпоинт взят, секция сброшена, партнёр поймал брошенный алмаз.
2. **Читаемость опасностей.** У каждого вида препятствия свой узнаваемый звук, и он
   звучит до того, как стало поздно.
3. **Комедия.** Через тайминг и контраст (серьёзная музыка — нелепая ситуация), а не
   через обилие «смешных» звуков.
4. **Атмосфера банка.** Тишина хранилища, гул серверной, шаги по мрамору.

## Связь со звуком в коде

- Звук — подписчик на сигналы, как HUD. Сигналы уже испускаются на каждой машине в одном
  порядке (`ARCHITECTURE.md`, «События»), поэтому **звук никогда не идёт по сети**: нет
  RPC «сыграй звук». Каждая машина играет звук по своему сигналу.
- Компонент звука — отдельный дочерний узел (`DiamondAudio`, `PlayerAudio`,
  `GuardAudio`…), который в `bind_*` подписывается на сигналы владельца. Логику игры он
  не меняет.
- **Кто слышит.** Звуки мира — всем, позиционно (`AudioStreamPlayer3D`). Звуки «только для
  себя» (своя выносливость, свой интерфейс) — только у владельца персонажа
  (`is_multiplayer_authority()`), без позиции (`AudioStreamPlayer`).
- Числа (громкость, дистанция, высота тона по прочности) — в конфиге (`*AudioConfig` +
  `.tres`), не в константах.
- Сброс секции пересоздаёт `Content` — звуки внутри него обрываются. Длинный звук,
  который должен пережить сброс (акцент сброса), играет узел вне `Content`.

## Шины

| Шина | Что | Примечание |
|---|---|---|
| Master | всё | |
| Music | музыка | громкость в настройках |
| SFX | звуки мира | громкость в настройках |
| UI | интерфейс | громкость в настройках |
| Ambience | атмосферы зон | отправка в SFX или Master |

Громкости шин сохраняются вместе с настройками игры (`ConfigFile`, этап «настройки» в
плане сохранений), не в `.tres`. Изменение раскладки шин (`default_bus_layout.tres`) —
через H2.

## Godot 4.4: что использовать

- `AudioStreamRandomizer` — вариации одного звука (шаги, удары) без повторов.
- `AudioStreamInteractive` (клипы и таблица переходов) и `AudioStreamSynchronized`
  (синхронные слои с отдельной громкостью) — для адаптивной музыки; оба есть в Godot
  4.3+, значит, в 4.4.1 тоже. Это ресурсы, их ставят в `stream` плеера.
- `max_polyphony` у плееров — ограничить число одновременных голосов.
- `Area3D` с переопределением реверберации (`reverb_bus_*`) — акустика помещений,
  ставит левел-дизайнер.
- Перед использованием свойства — сверка со справочником классов 4.4.1 (путь — в
  `CLAUDE.md`).

## Файлы

- Музыка и длинные петли — `.ogg`; короткие звуки — `.wav` (или `.ogg`, если файл
  большой). Петли — с настроенным loop в импорте.
- Папки: `audio/music/`, `audio/sfx/<фича>/`, `audio/ui/`, `audio/ambience/`.
- Имена: `snake_case`, по событию: `diamond_damaged_heavy_01.wav`.
- Громкость исходников выровнена по слуху между собой (нормализация при подготовке);
  итоговый баланс — шинами и конфигом.
- Каждый файл — строка в `assets/LICENSES.md` по `docs/art/ASSET_POLICY.md`.

| Событие (сигнал) | Звук | Кто слышит |
|---|---|---|
| `Diamond.picked_up`, `put_down` | взял/положил | все, 3D |
| `Diamond.passed` | передача | все, 3D |
| `Diamond.thrown`, `caught` | бросок, ловля | все, 3D |
| `Diamond.damaged` | удар, 3 ступени по оставшейся прочности | все, 3D |
| `Diamond.destroyed` | разрушение | все |
| `Stamina.changed` (низкая), `depleted` | тяжёлое дыхание, выдох | только владелец |
| касание лазера | треск/сирена | все, 3D |
| поимка охраной | акцент «попались» | все |
| `checkpoint_reached` | акцент чекпоинта | все |
| `section_reset` | «перемотка» | все |
| лазер рядом | гул луча | все, 3D, по дистанции |
